## Memory Block

**工作背景**
用户拥有跨多行业的丰富创业经历，覆盖有机化肥、汽配、商业操盘、连锁餐饮、电商直播、扣肉经销、越南Shopee/TikTok等领域。当前核心推进三大实体项目：贵州罗甸县剪粉店（计划投资5万，目标18个月开10家连锁）、柳州市啤酒代理（广西总代朋友可提供500件支持）、运河货运（计划购置5000吨货船，有深圳海关同学资源待激活），扣肉经销业务持有经市场验证的盈利数据但尚未开单。技术环境使用Windows 10（i7-7700K/32GB），通过WorkBuddy（用户名盛龙科技）与GitHub备份（github.com/wushiyibeili3/workbuddy-backup）管理8个已安装技能（含金枪大叔、罗永浩、女娲、钢铁尽调、华杉等），借助huashu-nuwa技能蒸馏华杉（华与华创始人）思维模型，作为商业分析与咨询的核心框架。核心优势为品牌运营能力与抖音本地生活引流经验，商业扩张以流量思维驱动，追求快速打爆和连锁化。做商业决策前常让AI生成详细问卷/清单用于实地调研。茉莉花茶行业调研持续推进，采用递进式研究策略——从产品创新到竞争格局逐步深入，近期新拓展全球市场研究维度，覆盖欧盟、北美、南美、东盟及非洲近5年格局；国内重点关注京派品牌（北京京张、一元、裕泰龙）及安徽猴王等龙头企业，同时正在全球范围内搜索并收集茶叶相关书籍资料。正在开展冶金橡胶辊（挤压辊）及热轧工作辊刮水板相关的橡胶配方细节（比例、硫化体系、工艺参数）研究与文档下载任务。正在构建钢铁企业B2B客户尽调技能，专注备品备件、工业耗材、设备技改、工程服务方向的拓客情报提取，要求输出结构化、可直接指导拓客动作的尽调报告，基于标准化框架与模板，技能输出结果统一保存至腾讯文档专用文件夹。持有Java小程序商城源码（含二级分销与会员功能），业务模式为转售/白标交付与轻量定制，原开发员工已离职且未留下配置或部署文档，需在非技术背景条件下推进业务。所有报告输出格式严格要求为PDF（无法下载时保存本地PDF副本），不接收Markdown格式。

**个人背景**
用户Qiang，44岁，广西柳州人，现居贵州罗甸县，开封有门面资源。用户为非技术背景的生意人，不会写代码。沟通与决策风格鲜明：偏好AI以名人视角（罗永浩、华杉、雷军、郭德纲）进行商业分析对比；分配任务时会指定具体格式要求，偏好可打印的A4版问题清单；决策时需多选项对比，且报告必须详细结构化并包含表格和数据分析，提供精确数据点；请求每日固定时间定期汇报监控任务结果；行动前要求先汇报当前状态，确认后再操作，遵循"先汇报、再确认、后执行"的交互逻辑。执行任务时偏好先问澄清问题再以清晰工作模块化输出，重视售前合同文档（需求确认书+技术任务确认书）以防范围蔓延。执行层面偏好直接执行而非调试，倾向可执行的方案和详细清单，遇执行困难时倾向找新方向而非坚持——曾因缺3000元启动资金而放弃夜市摆摊计划。使用飞书开放平台API管理个人日历事件（涉及OAuth授权流程），偏好结构化输出如分类表格，报告必须以PDF格式交付。无法下载网页内容时，倾向复制内容并本地保存为PDF副本。
