# 行业赛道与产业链深度研究

## 能力定位

对任意产业链/行业赛道进行系统化研究分析，核心目标是从产业链结构中定位**最能持续获取超额利润的环节**，并将其映射到有实证支撑的上市公司标的。

**角色设定**：以顶级产业投资研究员的视角执行分析。

**底层逻辑**：不找需求最强的公司，找供给弹性最差的环节。当一个环节出现供给瓶颈（产能受限 + 需求刚性 + 替代困难），对应的上游稀缺资源/材料天然具备高壁垒与高确定性。

**执行原则**：
- 用产业逻辑排序，不用涨幅排序——涨幅是果不是因
- 先拆链，后映射公司——不先列股票
- 所有关键数字必须标注来源、日期和证据等级；无来源的内容标为「待核验」
- 不荐股，不输出买入/卖出/目标价/仓位建议；最终输出是研究线索，不是投资建议

> **加载顺序**：先加载 `wb-finance-skill` 红线，再取数。正式报告默认 HTML；硬约束见 wb-finance；视觉为产业链结构风（上中下游 pastel + SVG），见 `references/html_template.md`。

## 启动分析前的核心校验

在启动正式分析前，先回答三个核心问题：

1. **需求是否真实？** 需求来自谁？是否有公告、财报、招标、资本开支、政策或行业数据支撑？是短期脉冲还是可持续 1-3 年？
2. **瓶颈在哪里？** 哪一层扩产最慢？哪一层替代最难？哪一层客户认证周期最长？哪一层良率、设备、材料、工艺或供应商数量构成硬约束？
3. **A 股映射是否有证据？** 哪些 A 股公司真实覆盖这个卡点？相关业务是否有收入、订单、客户、产能、认证、募投或公告证据？是主营业务还是边缘业务/概念蹭热点？

## 研究流程

### 阶段 A（可选）：信号漏斗扫描 —— 全市场暴涨机会发现

> 适用于「不知道分析什么行业，想从全市场信号出发发现机会」的场景。如果用户已经指定了要分析的产业链，直接跳到阶段 B。

主动发现式方法论。不预设行业，从异动信号出发，反向定位行业、环节和标的。核心逻辑：**多个独立信号同时指向同一个环节 = 高确定性机会**。

#### 六阶信号筛选

```
全市场信号扫描（第一阶）→ 信号聚类与行业定位（第二阶）→ 爆发因子匹配（第三阶）
→ 核心环节定位（第四阶）→ 标的锁定（第五阶）→ 时机判断（第六阶）
```

**第一阶：全市场信号扫描** — 从六类信号出发，不预设行业和来源：

1. **涨价信号**：周涨幅>5%、月涨幅>10%、季度涨幅>20%、创历史新高
2. **扩产/投产信号**：扩产公告、新增产能、设备订单激增。重点关注扩产困难（>24月）的品种
3. **认证/突破信号**：进入头部客户供应链（AVL）、通过国际认证、首次实现国产化
4. **政策/地缘信号**：产业政策出台、制裁/出口管制升级、反制措施
5. **财报异动信号**：营收环比增速>30%、净利润环比>50%、合同负债大增
6. **资金/筹码信号**：龙虎榜机构净买入、北向资金持续流入、融资余额快速上升

补充五类供给端关键词触发：供给冲击（停产/检修/断供/出口管制）、需求爆发（订单排到/供不应求/追单）、价格/库存（跳涨/上调报价/库存见底）、替代/认证（替代进口/首次通过/AVL导入）、产能瓶颈（扩产不及预期/设备到货延迟/爬坡困难）。

**数据获取方式**（仅用可信 skill）：

- **涨价信号**：用 `westock-tool ranking` 按涨跌幅排行扫描（如 `ranking qt_chg_interval --orderby ChgPct5D`），用 `westock-data hot stock` 获取热搜榜异动
- **扩产/认证/政策信号**：用 `neodata-financial-search` 自然语言搜索（如「近期产能扩张公告」「XX行业 扩产计划」「国产替代认证突破」），可获取研报和新闻中的信号
- **财报异动信号**：用 `neodata-financial-search` 搜索（如「营收环比增长超30% 的公司」「净利润环比暴增」），或用 `westock-tool event earnings_schedule` 跟踪业绩预约披露
- **资金/筹码信号**：用 `westock-tool ranking` 的资金流入指标（`cap_main_5d`、`margin_chg_d` 等），用 `westock-data lhb --type institution` 查龙虎榜机构动向
- **供给端关键词**：用 `neodata-financial-search` 按关键词搜索（如「停产检修 供给冲击」「订单排到 供不应求」）

每个信号记录：时间戳、环节/品种、信号类型、边际变化、可靠度（官方=高/权威媒体=中/传闻=低）。

**第二阶：信号聚类与行业定位** — 将分散信号按「环节」聚类，统计信号密度和多样性。

| 信号类型数 | 信号总数 | 共振等级 | 行动 |
|-----------|---------|---------|------|
| ≥5种 | ≥10个 | S级 | 必须深入分析 |
| 4种 | 7-9个 | A级 | 重点分析 |
| 3种 | 5-6个 | B级 | 观察跟踪 |
| ≤2种 | <5个 | C级 | 暂不关注 |

**第三阶：爆发因子匹配** — 对多信号共振的环节，用爆发六因子评分筛选（满分12分）。

| 因子 | 评估问题 | 满分2分条件 |
|---------|---------|------------|
| ① 稀缺性（卖铲人） | 是不是所有下游都绕不开？ | 下游分散+消耗品+不可替代 |
| ② 替代弹性 | 有没有进口依赖？国内能不能干？ | 海外占比高+技术已突破 |
| ③ 补库/缺口 | 是不是缺货且短期补不上？ | 缺口>5%+扩产>12月 |
| ④ 议价权 | 能不能说涨价就涨价？ | 占下游成本<5%+已涨价 |
| ⑤ 业绩映射 | 有没有订单/合同负债暴增？ | 在手订单>1年营收 |
| ⑥ 市值水位 | 估值高不高？有没有预期差？ | PE低位+成长性高 |

≥10分=S级；7-9分=A级；5-6分=B级；<5分=C级。注意：单一涨价信号无供给收缩或需求增长底层逻辑的，降级为周期波动，不上榜。

**第四阶：核心环节定位** — 在通过因子筛选的行业中，拆解产业链为5-8个环节，对每个环节做六因子快速评分，按总分排序找出最高分环节（核心环节）。环节选择优先级：卖铲人指数 > 国产替代弹性 > 涨价弹性 > 扩产难度 > 估值便宜度。

**第五阶：标的锁定** — 在核心环节内，通过六阶信号筛选锁定3-5只标的：

数据获取：用 `westock-data search --type sector` 搜索相关板块，用 `westock-data sector constituent` 获取成份股，用 `westock-tool filter` 按条件筛选（如 PE ≤ 30x、毛利率趋势等），用 `westock-tool ranking` 做资金面排序。

1. AVL等级 ≥ Tier-1
2. 产能利用率 ≥ 85%
3. 在手订单/年营收 ≥ 1.0
4. PE ≤ 30x（或 PS ≤ 10x）
5. 毛利率趋势向上或稳定
6. 机构持仓+资金流入

**第六阶：时机判断** — 六维时机评估（每维0-10分，满分60分）：库存周期、产能周期、价格周期、情绪周期、资金周期、估值周期。≥48分=最佳时机；36-47分=较好；24-35分=一般；<24分=不佳。

**必须规避的陷阱**：
1. 勿把「涨价」当唯一依据：仅有下游补库导致的一波流涨价、无供给侧「硬约束」，持续性差，不上榜
2. 警惕「众所周知」的机会：信号出现在财经媒体头版且已被充分演绎，不视为新信号
3. 海外信号必须映射国内：海外某材料暴涨，必须反问国内有无对应替代/出口受益标的，若无则仅做记录

信号漏斗扫描的内容结构参考 `references/gold-mine-report-templates.md`（含全市场扫描日报、行业深度报告、标的快速诊断、预选池等）。**正式交付默认写成 HTML**（可沿用 `references/html_template.md` 的样式体系），仅当用户明确要求 Markdown 时才用纯文本/Markdown。

扫描完成后，对识别出的高确定性行业，进入正式分析流程（阶段 B 起）。

### 阶段 B：产业链全景拆解

对目标产业链进行 BOM（Bill of Materials）式逐层拆解，从终端需求反向梳理至上游原材料。

**拆解结构（根据产业特点二选一或结合使用）：**

**方案 A — 上中下游分层**（适用于制造业/硬件产业链）：

```
上游（材料+设备）
  ├── 材料：关键原材料、辅料、耗材等
  └── 设备：核心生产设备、检测设备等

中游（制造/集成）
  ├── 核心零部件/组件
  ├── 制造/封装/测试
  └── 模组/品牌/集成

下游（应用场景）
  └── 按行业或场景分类
```

**方案 B — L0-L4 层级拆解**（适用于复杂技术赛道，输出 10-20 个候选卡点线索）：

| 层级 | 含义 | 关注点 |
|------|------|--------|
| L0 | 终端需求 | 最终应用场景、需求真实性 |
| L1 | 系统/集成 | 整机、平台、交付、客户认证导入 |
| L2 | 核心部件 | 决定性能/交付的关键部件、技术、良率、产能 |
| L3 | 材料/工艺/设备 | 原材料、制造工艺、生产设备、国产化进度、扩产周期、设备硬约束 |
| L4 | 上游资源 | 基础原材料、能源、上游供给稳定性 |

**对每一层/每一环节，必须解释：**
- **大白话**：这个环节到底在做什么（零基础能懂）。鼓励使用通俗类比（如「电子布=混凝土里的钢筋」「HBM=48车道高速路 vs DDR4=双车道」）
- **为什么重要**：它的产业地位
- **代表公司与典型毛利率区间**（如已知）
- 用箭头标注价值流向

**数据获取方式（仅用可信 skill）：**

- **产业链全景信息（竞争格局、技术壁垒、上中下游结构）**：用 `neodata-financial-search` 自然语言搜索：
  ```bash
  python3 scripts/query.py --query "{产业链名称} 产业链 上中下游 技术壁垒 竞争格局"
  python3 scripts/query.py --query "{产业链名称} 行业分析 市场格局"
  ```
  `neodata-financial-search` 会同时召回结构化 API 数据和研报/新闻/公告等文档，涵盖板块分析、行业热点驱动原因、个股基本面等。

- **板块成份股与行情数据**（A 股板块分析时）：用 `westock-data` 拉取：
  ```bash
  westock-data search "{板块名称}" --type sector       # 搜索板块代码
  westock-data sector info {板块代码}                    # 获取板块概况
  westock-data sector constituent {板块代码}             # 获取成份股列表
  westock-data quote {逗号分隔的代码列表}                 # 批量获取行情（每批 ≤50 只）
  ```
  > 使用 westock-data 时必须核查数据：逐只核对股票名称与代码是否匹配、市值数量级是否正确（总市值 ÷ 1e8）、代码不能张冠李戴（历史错误：沃格光电 sh688127 是错的，应为 sh603773）。

- **个股财报与基本面**：用 `westock-data finance {代码}` 获取财务报表，或用 `neodata-financial-search` 自然语言查询（如「{公司名} 最新季度毛利率」）。

### 阶段 C：瓶颈识别与关键环节筛选

**瓶颈分级**（S1/S2/S3）：

| 等级 | 含义 | 特征 |
|------|------|------|
| S1 | 极高壁垒 | 扩产周期 18-36 个月，全球仅 1-3 家能做，不可替代 |
| S2 | 高壁垒 | 扩产周期 12-18 个月，国产龙头关键卡位 |
| S3 | 结构性紧缺 | 扩产周期 6-12 个月，供给阶段性不足 |

**四重筛选标准**（用于锁定关键环节）：

| 筛选标准 | 判断依据 |
|---------|---------|
| **高增长** | 未来 3-5 年 CAGR > 行业平均水平 |
| **高利润** | 毛利率 / 净利率显著高于产业链均值 |
| **高壁垒** | 技术、牌照、网络效应、规模效应等构成的护城河 |
| **供给受限** | 产能扩张受制约（资本密集、认证周期长、资源稀缺等） |

输出格式：用表格列出候选环节及每项标准的符合程度（✓ / ✗ / 待验证），最终标注「★ 咽喉点候选项」。

**数据获取**：行业增速和毛利率数据用 `neodata-financial-search` 搜索（如「{环节} 行业增速 CAGR」「{环节} 毛利率 行业均值」）；个股毛利率用 `westock-data finance {代码}` 查询。

#### 附：技术迭代溯源法 —— 技术升级上游资源挖掘

> 当瓶颈源于技术迭代升级时，可用此方法深入溯源至上游稀缺资源端。

找到技术升级逼出的刚性瓶颈，溯源到最上游的资源端。每一次技术迭代都会对某个环节提出更高的物理要求（散热、传输带宽、封装工艺等），当传统材料/工艺无法满足时，瓶颈对应的上游稀缺资源/材料，往往就是壁垒最高、确定性最强的投资机会。

**六个步骤依次执行：**

1. **理解技术升级本身**：是哪一代产品/架构/标准的升级？新老之间核心参数变化是什么（功耗、速率、尺寸等）？这次升级的「方向」是什么？
2. **找到物理瓶颈**：散热（功耗大幅提升，传统散热方案失效？）、传输（带宽/速率提升后，传统材料跟不上？）、封装（芯片尺寸/集成度变化后，封装工艺遇到瓶颈？）、其他（电源、连接器、基板等出现新的极限要求？）。瓶颈在哪里，机会就在哪里。
3. **溯源到上游材料**：这个瓶颈要用什么新材料/新工艺来解决？这种材料的关键元素/原料是什么？谁是这种材料的上游资源端？
4. **验证稀缺性**：资源集中度（全球产能/储量集中在哪些国家/地区）、政策壁垒（是否有出口管制、开采限制）、技术壁垒（提纯/加工技术门槛有多高）、供需缺口（当前供给能否满足增量需求）
5. **判断产业周期**：实验室/验证阶段 → 量产启动阶段（重点关注：确定性高、市场尚未充分定价）→ 大规模放量阶段 → 成熟/衰退阶段
6. **找A股映射**：列出所有相关标的，逐一筛选核心受益方，给出重点关注标的及理由

**数据获取**：技术迭代信息用 `neodata-financial-search` 搜索（如「{技术} 新一代 参数升级 技术路线」），材料信息用 `neodata-financial-search` 搜索（如「{材料} 产能 全球分布」）+ `westock-data macro indicator` 查相关宏观数据。

注意事项：每一步都需要有数据/事实支撑，不要凭感觉下结论；若某一步缺乏足够数据，应明确指出数据缺口，而非强行推测；不同技术产业的瓶颈类型不同（散热/传输/封装/其他），不要机械套用。

3. **替代风险**：是否存在替代方案？（技术替代、模式替代、跨赛道替代）

### 阶段 E：公司映射与证据复筛

将产业链关键环节映射到具体 A 股标的，并对候选公司做证据校验。

**筛选非对称标的**（适用于挖掘中小市值机会）：

- 市值区间：默认 30-150 亿元人民币（可由用户指定）
- 机构覆盖率低：未被广泛覆盖的中小盘股
- 细分领域隐形冠军：在瓶颈环节有独特技术或产能优势
- 低成本占比 + 高失效风险：在终端 BOM 中成本占比极小，但一旦失效/换料需重新认证

**证据等级标准**（全程统一采信规则）：

| 等级 | 含义 | 来源类型 |
|------|------|----------|
| A 级 | 核心证据 | 公告、年报、半年报、招股书、交易所互动、招标/中标公告 |
| B 级 | 辅助判断 | 机构调研、管理层交流、权威行业数据、客户供应链公开信息 |
| C 级 | 仅作参考 | 券商研报、媒体报道、行业文章 |
| D 级 | 仅线索，不可当结论 | 社交媒体、KOL、论坛、传闻 |

**数据获取**：
- A 级证据用 `westock-data notice list {代码}` 查公告，`westock-data finance {代码}` 查年报/财报
- B/C 级证据用 `westock-data report {代码}` 查研报，`westock-data news article {代码}` 查新闻
- 或用 `neodata-financial-search` 自然语言查询（如「{公司名} 客户 供应链 认证」「{公司名} 定增 募投 产能」）

| 公司 | 股票代码 | 对应产业链环节 | 业务纯度 | 公开证据内容 | 证据等级 | 现有证据不能证明的内容 | 初步归类 |
|------|----------|----------------|----------|--------------|----------|------------------------|----------|

### 阶段 F：财务拐点穿透

针对「重点线索」类标的，审查财务数据，寻找供需失衡引发的拐点信号。

**关注指标：**
- **毛利率**：过去两季度是否出现爆发性拐点（连续提升、同比跳升）
- **净利率**：是否与毛利率同步改善（排除一次性收益）
- **CapEx（资本支出）**：是否在秘密爬坡（扩产先行信号）
- **营收增速**：是否加速且主要由瓶颈业务驱动

**数据获取**：用 `westock-data finance {代码} --num 8` 获取最近 8 期财报数据，或用 `neodata-financial-search` 查询（如「{公司名} 近两年 毛利率 净利率 营收增速」）。

**财务拐点评级：**

| 评级 | 含义 | 特征 |
|------|------|------|
| ★★★★★ 超级拐点 | 毛利率+净利率+CapEx+营收四线共振 | 强确定性 |
| ★★★★☆ 明确拐点 | 毛利率+营收双升，CapEx 启动 | 高概率 |
| ★★★☆☆ 早期拐点 | 毛利率初步改善，其他指标待确认 | 需跟踪 |
| ★★☆☆☆ 假摔型 | 毛利率波动但非趋势性改善 | 谨慎 |

### 阶段 G：红队反向证伪

扮演持有大量空头的分析师，从以下维度为「重点线索」标的撰写证伪报告：

| 证伪维度 | 审查问题 |
|---------|---------|
| **技术路径替代** | 是否有新技术路线可能绕过该瓶颈环节？12-18 个月内是否可能出现替代方案？ |
| **大客户自研/二供风险** | 下游大客户是否有能力/动机自研替代？是否存在二供三供分流风险？ |
| **供应链断裂** | 地缘政治、制裁、原材料断供等系统性风险 |
| **行业价格战** | 行业是否面临产能过剩引发的价格战风险？ |
| **业务实质** | 业务是否为低毛利代工/边缘业务？市场是否已提前充分定价？ |

**数据获取**：用 `neodata-financial-search` 搜索证伪线索（如「{公司名} 替代方案 竞争」「{环节} 产能过剩 价格战」），用 `westock-data risk {代码}` 查风险事件。

输出风险表格：

| 公司 | 最大潜在风险 | 现有证据能否缓解风险 | 缺失关键数据 | 风险等级 |
|------|-------------|---------------------|-------------|----------|

风险等级仅可选：低 / 中 / 高 / 证据不足。

### 阶段 H：动态跟踪与熔断机制

**里程碑可选类型：** 订单/中标/送样认证进展、批量产品交付、赛道业务收入占比提升、募投产能爬坡投产、毛利率维持/改善、头部客户合作落地

**跟踪表格：**

| 公司 | 跟踪里程碑 | 最晚观察时间 | 达成代表什么信号 | 未达成代表什么信号 |
|------|-----------|-------------|-----------------|-------------------|

**熔断规则（研究跟踪用，非自动交易指令）：**

| 优先级 | 触发条件 | 跟踪动作（条件框架） |
|--------|---------|----------------------|
| 🔴 红色（极高） | 关键里程碑未按时达成 | 将该线索降为「失效观察」；若用户持仓，提示复核论点是否仍成立（由用户自行决策） |

### 阶段 J：五维星级评级与分梯队排序

**五大维度 ⭐️ 评级：**

| 维度 | 含义 | 权重 |
|------|------|------|
| 产业逻辑 | 有没有被政策/技术/需求确认的产业趋势 | 核心 |
| 增量空间 | 是新增量还是存量博弈 | 重要 |
| 不可替代性 | 在产业链中是否不可替代 | 重要 |
| 技术壁垒 | 工艺/配方/专利护城河 | 加分 |
| 不可复制性 | 竞争对手短期内能否追上 | 加分 |

⭐️ 含义：
- ⭐⭐⭐⭐⭐ = 逻辑极硬（全球仅 1-3 家能做 / 不可替代且增量确定）
- ⭐⭐⭐⭐ = 逻辑清晰（国产龙头 / 关键卡位）
- ⭐⭐⭐ = 受益逻辑成立但竞争格局更分散
- ⭐⭐ = 受益但非核心增量方向

**分梯队排序**（按逻辑硬度，不按涨幅）：
- **第一梯队** ⭐⭐⭐⭐⭐：逻辑最硬，3-6 家公司（完整五维度详解）
- **第二梯队** ⭐⭐⭐⭐：逻辑清晰，关键卡位，5-10 家公司（精简维度，如只列产业逻辑+不可替代性）
- **防守型** ⭐⭐⭐ 及以下：受益但非核心增量，表格形式（一句话逻辑）

#### 附：瓶颈五维校验 —— 个股级真伪瓶颈判断

> 适用于需要对单个标的做深度瓶颈验证的场景，可替代或增强上述五维评级。

**核心哲学**：不找需求最强的公司，找供给弹性最差的环节。真瓶颈=消耗性材料+寡头供给+无替代方案。设备/工具类产品不构成瓶颈。

**Step 1：定位产业链位置** — 是消耗性原材料还是资本设备？处于几阶传导？（一阶直接受益者排除，重点找二阶以上）与终端需求的关联是线性消耗还是间接概念？

**数据获取**：用 `neodata-financial-search` 搜索（如「{标的} 产品 是消耗性材料还是设备」「{标的} 产业链位置 上下游」）。

**Step 2：数据收集** — 最强信号：有无股权投资/长约锁定产能？产能是否被预订至18个月以后？强信号：有无涨价函？交期是否翻倍？guidance是否上调？中等信号：研报是否上调预期？下游capex是否增加？反向验证：对比产品和服务的全球供给状态。

**数据获取**：
- 产能/长约信息：`neodata-financial-search` 搜索（如「{标的} 长约 产能锁定 股权投资」）
- 涨价/交期信号：`westock-data news article {代码}` 或 `neodata-financial-search`
- 研报/CapEx：`westock-data report {代码}` + `westock-data finance {代码}`

**Step 3：五维评分（1-5分制，5分为极端瓶颈）**

| 维度 | 核心问题 | 高分段特征（4-5分） | 低分段特征（1-2分） |
|------|----------|---------------------|---------------------|
| 供给弹性 | 扩产要多快？竞争格局？ | 扩产周期18月+、寡头垄断、良率爬坡极难 | 标准设备、竞争分散、容易扩产 |
| N阶传导 | 与终端需求是线性关联？ | 每颗芯片/模块必消耗，量价线性挂钩 | 间接关联、非线性、传导链断裂 |
| 瓶颈紧张度 | 当前有无短缺信号？ | 涨价>30%、交期翻倍、库存见底 | 供给充足、价格稳定 |
| 机构盲区 | 机构覆盖程度？ | 小市值(<100亿)、无机构覆盖 | 大市值、被密集调研 |
| 地缘杠杆 | 供给由谁掌控？ | 中国垄断全球70%+供给、出口管制收紧 | 供给分散、进口替代型(被动) |

**数据获取**：各维度数据用 `neodata-financial-search` 查询（如「{标的} 扩产周期 竞争格局」「{标的} 产能 全球分布 中国占比」），机构覆盖度用 `westock-data report {代码}` 查研报数量判断，市值用 `westock-data quote {代码}`。

**Step 4：真伪瓶颈判断** — 总分≥18 → 「真瓶颈」标的；总分<15 → 「概念股」或「非瓶颈标的」，不推荐。

关键区分规则：
- 消耗性材料（每片必用）→ 可能为瓶颈；资本设备（一台用多年）→ 几乎不可能
- 有实际短缺信号（涨价/缺货/长约）→ 瓶颈已激活；只有叙事无信号 → 概念炒作
- 中国主动垄断供给 → 强地缘杠杆；中国被动替代进口 → 弱地缘杠杆

**快速甄别口诀**：
```
材料 vs 设备 → 材料才是瓶颈
消耗 vs 一次 → 消耗才有复购
涨价信号 → 真短缺已激活
概念叙事 → 可能只是炒作
中国卡别人脖子 → 最强地缘杠杆
中国替代进口 → 逻辑弱一档
PE极高（100x+）→ Narrative已定价，大概率不是盲区
```

**Step 5：输出结论** — 一句话结论（是否瓶颈标的、是否推荐）+ 五维评分表（含得分和判定依据）+ 核心逻辑拆解 + 风险提示。

五维评分参考案例见 `references/scoring-examples.md`（含正面案例：铟/WF6/钼，反面案例：莱伯泰科/锐科激光）。

## 多路径联动策略

> 分析框架中的多条路径可按以下方式组合使用：

1. **发现 → 深挖**：信号漏斗扫描（阶段 A）发现多信号共振的环节 → 进入正式分析流程（阶段 B 起）做全景拆解 → 对瓶颈环节用技术迭代溯源法溯源上游材料 → 对锁定的标的用瓶颈五维校验做最终瓶颈验证
2. **已知行业 → 落地**：从阶段 B 起执行完整分析流程 → 对瓶颈环节用技术迭代溯源法溯源 → 对候选标的用瓶颈五维校验做逐一评分和排序
3. **快速诊断**：瓶颈五维校验（阶段 J 附）独立使用，对用户指定的任意标的做瓶颈判断

## 使用约束与边界

1. **数据时效与来源**：金融行情/财报等必须通过可信 skill（westock-data / westock-tool / neodata-financial-search / wb-finance-skill）获取，禁止 clawhub / curl / 第三方行情 API。仅非行情类公开产业资料在可信 skill 未覆盖时可 WebSearch，并标「非一手来源」。所有数据必须标注来源或「暂无可靠来源」「估算值」。不确定的信息不得伪装为事实。对比分析必须使用同一口径的数据。
2. **产业链名称灵活适配**：用户指定什么产业链就分析什么，HBM/PCB/MLCC/光模块/存储芯片/AI/新能源车等均适用同一框架。
3. **标的筛选保守化**：优先选择「有公开可查的客户/产能/认证信息支撑」的公司，避免纯概念炒作标的。
4. **熔断指标可量化**：里程碑事件必须具体、可验证、有明确截止时间，避免模糊表述。
5. **市值/财务阈值可由用户覆盖**：默认 30-150 亿市值区间，用户可指定其他范围。
6. **不构成投资建议**：所有分析仅供参考，报告末尾应有免责声明。
7. **对于用户未指定的产业名称**，应主动确认后再启动分析。
8. **分析过程中若发现关键数据缺失**，应列出「待补充信息清单」供用户后续补充。
9. **公司分类严格限定为三类标签**：重点线索、观察线索、暂不适合作为案例，不可自行新增。
10. **默认输出 HTML**：正式研究报告默认写为自包含 `.html` 文件；仅当用户明确要求 Markdown 时改用 `.md`。

## 运行环境与外部依赖

### 可信 skill 数据源（强制）

本 skill 仅使用以下 4 个可信 skill 获取数据：

| 可信 skill | 关键能力 | 调用方式 |
|-----------|---------|---------|
| **westock-data** | A股/港股/美股行情、K线、财报、研报、新闻、公告、板块成份股、宏观经济、龙虎榜等 | CLI：`westock-data <命令> [参数]` |
| **westock-tool** | 条件选股（filter）、策略选股（strategy）、标签选股（label）、事件选股（event）、排行选股（ranking） | `node <skill目录>/scripts/index.js <命令> [参数]` |
| **neodata-financial-search** | 自然语言金融数据搜索：行情、财报、研报、新闻、公告、宏观、板块分析等 | `python3 scripts/query.py --query "..."` |
| **wb-finance-skill** | 金融分析方法论与本地可跑脚本（估值建模、量化因子、技术形态等） | 读取 references/ 获取方法论，执行 scripts/ 下脚本 |

### 其他依赖

- **文件写入**：默认生成自包含 HTML 报告；仅用户明确要求时生成 Markdown。使用环境内建的文件写入工具。

本技能为方法论框架；金融行情数据不依赖 clawhub / curl / 第三方行情 API / MCP。非行情类公开产业资料在可信 skill 未覆盖时，可按上文规则谨慎使用 WebSearch 并标注来源。
