# 瓶颈投资方法论核心框架

## 一、底层逻辑

AI超级周期 = 一系列supply bottleneck的轮番爆发。谁卡脖子，谁涨。

核心身份：AI supply chain派 / 产业链瓶颈猎手

## 二、四大基本准则

### 准则1：供给弹性至上
不找需求最强的公司，找供给弹性最差的环节。

判断维度：
- 扩产周期：越长越好（InP衬底18-24个月 vs 光模块组装3-6个月）
- 竞争格局：寡头垄断优于分散竞争
- 技术壁垒：良率爬升难度、工艺积累时间
- 产能集中度：产能集中在少数厂商/地区
- 客户验证周期：导入新供应商需要的时间

### 准则2：产业链N阶传导
不做表层AI（一阶），专注二阶、三阶传导。

传导模型：
```
一阶：Hyperscaler capex爆发（GPU采购）
  ↓
二阶：光模块/HBM/封装需求暴增
  ↓
三阶：光芯片/InP衬底/DSP/硅光代工产能紧张
  ↓
四阶：材料（磷化铟/锗/ABF膜）/设备供不应求
```

越往上游：市值越小 / 研究覆盖越少 / 供给弹性越差 / 潜在涨幅越大 / 波动越大

### 准则3：主题轮动 + 产业验证
识别产业趋势是否进入"加速区" → 高conviction重仓 → 瓶颈缓解信号出现 → 切换到下一个瓶颈。

加速区信号：
- Hyperscaler capex guidance上调
- 订单长约化（LTA从1年→3年→5年）
- 客户抢产能（预付款/股权投资锁定供给）
- 涨价函/交期延长公告
- 同业竞相扩产（但产能要1-2年后才释放）

### 准则4：叙事放大效应
用产业链逻辑讲故事，但要注意：被关注的标的可能形成"拥挤交易"——既是alpha来源，也是风险来源。

## 三、六大核心赛道

| 赛道 | 核心瓶颈 | 时间窗口 |
|------|----------|----------|
| AI光通信 | EML/CW激光器/InP衬底/DSP/硅光代工 | 2025-2028 |
| HBM/Memory | HBM产能/CoWoS/硅片/刻蚀设备 | 2025-2027 |

| AI电力/冷却 | 变压器/液冷/并网 | 5-10年 |

| AI基础设施材料 | InP衬底/锗/ABF膜/T-glass | 最长周期 |

## 四、瓶颈紧张度评分（1-5分）

| 分数 | 状态 | 典型信号 |
|------|------|----------|
| 5 | 严重短缺 | 涨价>30%、交期翻倍、客户预付锁产能、股权投资绑定 |
| 4 | 明显紧张 | 产能利用率>90%、开始涨价、LTA签订加速 |
| 3 | 偏紧 | 个别客户缺货、lead time小幅延长 |
| 2 | 平衡 | 供需基本匹配、价格稳定 |
| 1 | 宽松 | 产能利用率<70%、价格下行 |

## 五、信号优先级

最强信号：英伟达/hyperscaler签股权投资+长约 / 产能预订至18个月后 / 客户offer预付款抢产能
强信号：涨价函/交期延长 / 厂商guidance上调 / "拿不到货"反馈 / 竞品扩产
中等信号：研报上调需求 / 下游capex上调 / 展会积极信号
