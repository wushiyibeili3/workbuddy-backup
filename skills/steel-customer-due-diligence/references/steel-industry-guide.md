# 钢铁行业专属知识库

## 产线类型释义与备件需求映射

钢铁生产流程从上游到下游依次为：炼铁 → 炼钢 → 轧钢，各工序对应不同的设备类型与备品备件需求。

### 炼铁工序

| 产线类型 | 功能说明 | 关键设备 | 典型备品备件/耗材需求 |
|----------|----------|----------|----------------------|
| 高炉 | 将铁矿石冶炼成铁水 | 高炉本体、热风炉、上料系统、渣铁处理系统 | 冷却壁、风口、炉衬耐火材料、热风炉蓄热体、炮泥、沟料 |
| 烧结机 | 将粉矿烧结成块矿 | 烧结机本体、点火炉、除尘系统 | 台车篦条、炉篦、点火器烧嘴、除尘滤袋 |
| 球团 | 将精矿粉造球焙烧 | 造盘机、回转窑/竖炉 | 耐火材料、造球盘衬板 |

### 炼钢工序

| 产线类型 | 功能说明 | 关键设备 | 典型备品备件/耗材需求 |
|----------|----------|----------|----------------------|
| 转炉 | 将铁水脱碳炼成钢水 | 转炉本体、氧枪、烟罩、除尘系统 | 炉衬耐火材料（镁碳砖）、氧枪喷头、烟罩耐火材料、滑动水口 |
| 电炉 | 用废钢/直接还原铁炼钢 | 电炉本体、电极、变压器 | 石墨电极、炉衬耐火材料、水冷件 |
| 精炼 | 钢水进一步脱杂调温 | LF炉、RH真空脱气、VD炉 | 耐火材料、浸渍管、电极、合金加料系统 |
| 连铸 | 钢水浇铸成坯 | 连铸机本体、结晶器、二冷区 | 结晶器铜板、二冷喷嘴、扇形段辊子、中间包耐火材料 |

### 轧钢工序

| 产线类型 | 功能说明 | 关键设备 | 典型备品备件/耗材需求 |
|----------|----------|----------|----------------------|
| 热轧 | 将钢坯加热后轧制成板材/型材 | 加热炉、轧机机组、层流冷却、卷取机 | 轧辊、导卫装置、层流冷却喷嘴、除鳞喷嘴、加热炉滑轨 |
| 冷轧 | 在常温下将热轧卷进一步轧薄 | 酸洗线、冷轧机、脱脂线、退火炉 | 轧辊、酸洗槽设备、挤干辊、清洗喷嘴、退火炉辊 |
| 酸洗 | 去除氧化铁皮 | 酸洗槽、冲洗段、酸再生系统 | 酸槽内衬、挤干辊、喷淋管、酸再生催化剂 |
| 镀锌 | 在钢板表面镀锌防腐 | 锌锅、退火炉、气刀、光整机 | 沉没辊、稳定辊、气刀喷嘴、锌锅耐火材料、感应器 |
| 彩涂 | 在镀锌板表面涂覆有机涂层 | 清洗段、涂层机、固化炉 | 涂层辊、刮刀、固化炉网带、风机 |
| 中厚板 | 生产中厚度钢板 | 加热炉、轧机、热处理炉、剪切线 | 轧辊、热处理炉辊、剪切刀片、矫直辊 |
| 棒线材 | 生产钢筋、线材等长材 | 加热炉、轧机机组、冷却床 | 轧辊、导卫、吐丝管、冷床辊道 |

### 公辅工序

| 工序类型 | 功能说明 | 关键设备 | 典型备品备件/耗材需求 |
|----------|----------|----------|----------------------|
| 水处理 | 工业循环水、废水处理 | 冷却塔、水泵、过滤器、加药系统 | 滤芯、泵阀密封件、加药泵、冷却塔填料 |
| 除尘 | 烟气除尘、环保排放控制 | 布袋除尘器、电除尘器、脱硫脱硝 | 滤袋、骨架、脉冲阀、电场极板 |
| 能源动力 | 煤气、蒸汽、电力供应 | 锅炉、汽轮机、压缩机 | 阀门、密封件、过滤元件 |

## 行业核心政策与合规要求

### 超低排放改造
- 政策要求：2025年底前80%以上钢铁产能完成超低排放改造
- 改造内容：有组织排放治理（烟气脱硫脱硝除尘）、无组织排放管控、清洁运输
- **对供应商的机会**：除尘设备改造、脱硫脱硝耗材、环保监测设备、无组织扬尘治理设备

### 产能置换
- 政策要求：新建/改扩建炼铁炼钢项目必须严格执行产能置换
- 影响：老旧产能退出，新产能上马，带来设备更新需求
- **对供应商的机会**：新建产线设备配套、旧产线拆除期间替代供应

### 双碳目标
- 政策要求：钢铁行业碳达峰、碳中和路线图
- 改造方向：氢冶金试点、电炉短流程炼钢、余热余气回收利用
- **对供应商的机会**：节能降耗设备、余热回收装置、低碳工艺配套备件

### 绿色制造
- 政策要求：绿色工厂评价、水效领跑者、能效对标
- 影响：节水、节能、固废资源化利用成为刚需
- **对供应商的机会**：水处理耗材、节能改造设备、固废处理设备

## 常用术语表

| 术语 | 释义 |
|------|------|
| 高炉 | 利用铁矿石和焦炭冶炼铁水的竖炉，钢铁生产最上游 |
| 转炉 | 利用氧气将铁水中的碳脱除炼成钢水的炉子 |
| 电炉（EAF） | 利用电能熔化废钢炼钢的炉子 |
| 连铸 | 将钢水连续浇铸成钢坯的工艺 |
| 热轧 | 将钢坯加热后轧制成材的工艺 |
| 冷轧 | 在常温下将热轧卷进一步轧薄的工艺 |
| 酸洗 | 用酸液去除钢板表面氧化铁皮的工序 |
| 镀锌 | 在钢板表面镀锌以防腐的工序 |
| 粗钢 | 未经过轧制等加工的钢水铸坯 |
| 材（钢材） | 经过轧制等加工后的钢铁产品 |
| 产能置换 | 新建产能必须等量或减量淘汰旧产能的政策 |
| 超低排放 | 颗粒物、SO2、NOx排放浓度分别不高于10、35、50mg/Nm³的环保标准 |
| 备品备件 | 设备维修和更换用的零部件 |
| 框架协议 | 年度/季度采购框架，约定单价和总量，分批交货 |
| 合格供应商名录 | 通过准入审核后进入的可投标供应商名单 |
| 审厂 | 采购方到供应商工厂现场审核资质和能力的流程 |
| 欧贝 | 宝武集团旗下采购平台，原名宝钢采购 |
| 中冶系 | 中国冶金科工集团下属的设计院和工程总包方（如中冶赛迪、中冶南方、中冶京诚等） |

## 产线投产年限与备件需求关系

| 投产年限 | 设备状态 | 备件需求特征 |
|----------|----------|-------------|
| 0-2年 | 新设备磨合期 | 初始备件需求大（调试件、改造件），尚未进入稳定采购周期 |
| 3-8年 | 稳定运行期 | 常规备件为主，采购周期稳定，供应商格局已固化 |
| 8-15年 | 设备中年期 | 易损件更换频率上升，技改需求增加 |
| 15年以上 | 设备老化期 | 大修需求强烈，整体改造可能性高，新供应商切入窗口最佳 |

**提示**：在收集产线投产时间时，同步标注「上次大修时间」「上次技改时间」，用于判断当前所处的备件需求周期阶段。
